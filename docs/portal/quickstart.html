源码 Quickstart

阅读完整指南 →
1
启动 Mock API

在 Community 仓库根目录运行：

pnpm install
pnpm mock
2
创建一个观察 Job

每个请求都带上唯一的幂等键：

curl -X POST http://localhost:8787/v1/monitor-runs \
  -H 'content-type: application/json' \
  -H 'idempotency-key: quickstart-001' \
  -d '{"capability_id":"observe.ai_answer","prompts":["mock quickstart"],"turnaround_class":"best_effort","interaction_mode":"search"}'
3
查询结果

使用响应里的 Job ID 查询状态和 items。客户端应根据 status 与 result_state 判断生命周期。

curl http://localhost:8787/v1/jobs/job_demo_queued
curl http://localhost:8787/v1/jobs/job_demo_queued/items
