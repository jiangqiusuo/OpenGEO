# 工作台只读指标口径

版本：`workbench-metrics.v1`。源文件为 `apps/web/src/workbench-data.ts`，每项投影携带 `definitionVersion`、公式、计算范围和支持观察 ID。

这些指标针对当前已加载的虚构或 Mock 观察。有效观察依据 `quality.is_valid` 筛选，计算不会补取全部服务端分页；总览显示前5条，详情显示前20条，支持 ID 与指标计算使用全部已加载有效观察。一次加载不代表完整时间窗口或完整任务结果。

| 指标 | 分子 | 分母 / 展示 |
|---|---|---|
| 品牌提及率 | 有任一 `brand_mentions.mentioned` 为 true 的有效观察 | 已加载有效观察数 |
| 绝对 Top 3 | 该观察最小记录排名不大于3的有效观察 | 已加载有效观察数 |
| 自有域名引用率 | 检索来源 domain 精确匹配项目 owned_domains 的有效观察 | 已加载有效观察数 |
| 有效样本 | 有效观察数 | 数量；辅助比例为有效观察数 / 已加载观察数 |

当前视图未配置独立目标实体过滤；上述提及与排名依据演示记录的提及/排名集合。需要按实体计算时使用[指标包](../packages/metrics/README.md)的版本化定义，并单独接入视图。检索来源不等同回答明确引用，有效比例不等于 Job 完成度。

比例分母为0时显示 `—`，详情显示没有支持样本。无支持样本的非空范围可显示0%。每条详情只展示对应观察的回答和来源，不复用其他指标的样本。

计算规则变化须更新口径版本、测试和本文；文案或布局调整不改变数学含义。预设趋势和建议保持明确的演示标记，不用于这些计算。
