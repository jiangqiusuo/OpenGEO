# 产品界面与交互形态

OpenGEO Community 的主要交互形态是一个面向 GEO 运营人员的工作台。

## 工作台

工作台承载用户每天需要查看和操作的对象：

- 项目和品牌。
- 提示词集合。
- 监测任务及部分结果。
- 指标、趋势和证据。
- 内容、发布和复测。
- 用量与设置。

首页保持简洁，只展示当前周期最重要的指标和变化。用户点击指标后，再进入指标解释、样本范围和回答证据。

## 工作流

工作流是工作台内的一条业务路径：

```text
设置问题 → 执行监测 → 理解表现 → 生成内容 → 发布 → 复测
```

工作流不会要求用户离开工作台进入另一套产品。每一步都使用相同的项目、Job、Observation、Publication 和 Metric Result 概念。

## Agent

Agent 是工作台中的辅助入口，用于解释变化、检索证据、建议下一步和编排已授权操作。Agent 不替代工作台，也不会绕过用户确认直接发布内容、消费预算或修改项目。

## 当前原型边界

`apps/web` 当前用于验证页面结构和交互方向。指标依据抽屉已经可以使用；未接入数据或写操作的控件均显示“规划中”，点击后会出现状态提示。页面使用虚构数据，不连接外部服务。
